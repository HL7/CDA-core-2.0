# cda-core-2.0

Resources for Clinical Document Architecture (CDA) release 2.0

## CDA Schema

The [`schema/normative`](./schema/normative) folder contains the original published CDA Schema. This is the schema which is published with the base/core standard. This is mainly used for historical reference. See "CDA Schema Extensions" below for the latest version that includes all extensions, which most people will want to use.

## CDA Schema Extensions

The [`schema/extensions`](./schema/extensions/) folder contains an [`SDTC`](./schema/extensions/SDTC) folder which has the updated CDA schema with all SDTC extensions that are approved by HL7.

## CDA Stylesheet

The CDA Stylesheet is located at https://github.com/HL7/cda-core-xsl. It is currently being managed by Alex Henket for SDWG.

## FHIR Logical Models for CDA

The FHIR logical models for CDA have been moved to https://github.com/HL7/CDA-core-sd.

## Online Navigation of CDA

Files developed for ballot to place the CDA R2.0 standard [online](https://hl7.org/cda/stds/online-navigation) are included in the folder [```online-navigation```](./online-navigation).

## CDA Home Page

The landing page for [hl7.org/cda](https://hl7.org/cda) is included in the folder [```cda-home```](./cda-home), which is separate from the normative standard and maintained by CDA Management Group.
